# Changelog

All notable changes to XyKit are documented in this file.

## [Unreleased]

### Added

- MIT License file.
- English SpigotMC resource description and full BBCode documentation.
- Manual SpigotMC publishing checklist.

### Changed

- README now links to the SpigotMC publishing materials, changelog and license.

## [1.3.3] - 2026-07-11

### Changed

- Upgraded the provided Paper API dependency to `26.2.build.56-alpha`.
- Updated the supported platform to Paper 26.2.x while keeping Java 25 as the build and runtime requirement.
- Updated plugin metadata and Paper 26.2 upgrade documentation.
- Kept the existing kit, CDK, command and YAML data behavior unchanged.

## [1.3.2] - 2026-04-05

### Changed

- Upgraded the provided Paper API dependency to `26.1.1.build.20-alpha`.
- Raised the Java compilation target to Java 25.
- Added Paper 26.1 upgrade documentation.

## [1.3.1] - 2026-02-15

### Fixed

- Fixed data loss associated with upgrading from an older version.

### Changed

- Updated configuration documentation.

## [1.3.0] - 2026-01-25

### Changed

- Added support for Minecraft 1.21.11.

## [1.2.0] - 2025-12-11

### Fixed

- Fixed unlimited CDK use.
- Fixed configuration reload behavior.

### Added

- Stronger CDK uniqueness checks, null checks and detailed logging.

## [1.1.0] - 2025-10-18

### Added

- Batch CDK generation.
- CDK statistics and detailed redemption logging.
- Additional duplicate-code protection.

## [1.0.0] - 2025-10-18

### Added

- Initial starter-kit and CDK-kit release.
- YAML data storage, permissions and multiple command execution modes.
